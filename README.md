# HireMate – AI Interview Coach

An AI-powered interview preparation platform that helps students and recent graduates practice realistic job interviews, get personalized feedback, and track their progress over time.

## ✨ Features
- **AI mock interviews:** role-specific interview questions generated by large language models
- **Personalized feedback:** AI evaluation of each answer with concrete suggestions for improvement
- **Performance analysis:** insight into strengths and weak spots across sessions
- **Progress tracking:** history of past interviews to measure improvement over time
- **Resume upload:** PDF upload and parsing to tailor the interview experience
- **Secure accounts:** JWT-based authentication with hashed passwords

## 🛠️ Tech Stack
| Layer | Technologies |
|---|---|
| Frontend | React (Vite), React Router, Tailwind CSS, Axios |
| Backend | Node.js, Express, JWT, express-validator, Multer |
| Database | Supabase, Firebase |
| AI | Anthropic Claude, OpenAI, Google Gemini APIs |
| Testing | Jest |

## 📁 Project Structure
```
hiremate-ai-interview-coach/

└── docs/       # Documentation, database schema, AI prompt design
```

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- API keys for Claude / OpenAI / Gemini, plus Supabase and Firebase project credentials

### Backend
```bash
cd backend
npm install
# create a .env file with your API keys and database credentials
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Run tests
```bash
cd backend
npm test
```
